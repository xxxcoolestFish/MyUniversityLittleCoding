# MyUniversity

本科期间自己写的小程序合集，每一个文件夹都是一个独立的小项目。

---

## 项目列表（按代码量排序）

### 1. Learning Self-Discipline Assistant（学习自律助手）

**Qt C++ 桌面应用** | ~3,200 行

一款英语单词学习与自律管理工具。用户可以创建自己的单词本、添加单词、进行英汉互译检测，系统会自动记录学习数据和错词本。内置奖励机制——完成学习任务后可获得虚拟奖励（苹果、牛奶、薯片、辣条、奖杯等图标），将枯燥的背单词过程游戏化。

主要功能：
- 单词本管理与单词添加
- 英译汉 / 汉译英 检测模式
- 学习记录自动存档（按日期）
- 错词本自动收集
- 奖励结算系统

### 2. Portable Word Reciting Tool（便携单词背诵工具）

**8051 单片机 C 语言嵌入式项目** | ~2,300 行

基于 STC89C51 单片机的便携式单词背诵硬件。两个设备通过串口（9600 bps）配对通信，一方发送单词数据，另一方接收并进入背诵检测模式。使用 12864 LCD 液晶屏显示单词，支持交互式背诵与对答案功能。

主要功能：
- 12864 LCD 驱动（字符/汉字显示）
- 双机串口配对通信（自定义握手协议）
- 单词发送与接收模块
- 交互式背诵检测（判断对错并反馈）
- 数据存储读取（EEPROM）

### 3. Home Internet of Things Information System（家庭物联网信息系统）

**树莓派 Python 项目** | ~2,300 行

一个完整的家庭物联网系统，分为**控制中心（Center Machine）**和**边缘设备（Edge Machine）**两部分，通过 Socket 加密通信联动。

控制中心功能：
- Zigbee 无线数据采集
- 超声波距离检测（HC-SR04）
- 温湿度传感器（DHT11）
- 闹钟模块（触摸传感器 + 继电器）
- 高德天气 API 接入
- 自定义加密通信协议（oO 编码 + 汉字加密）

边缘设备功能：
- 距离保护警戒模式
- 远程指令执行
- IP 自动发现
- 文本消息收发

### 4. Child Growth Planning Report Generator（儿童成长规划报告生成器）

**Qt C++ 桌面应用** | ~500 行

一个辅助生成儿童成长规划报告的桌面工具，内置钢琴音乐播放功能，可配合报告生成过程营造氛围。支持自定义快捷键与菜单操作。
